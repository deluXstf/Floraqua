# Floraqua

Flutter-приложение для учёта комнатных растений: распознавание по фото через Gemini, сезонные рекомендации по уходу и локальные напоминания.

## Запуск

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

Сборка desktop-версии Windows: `flutter build windows --release`.

## Структура проекта

- `lib/screens/` — экраны и координация состояния; пользовательские операции сада вынесены в `GardenPlantActions`.
- `lib/widgets/` — повторно используемые части интерфейса: панель сада, коллекция/раскладка растений, карточки, редактор, просмотр фото и UI-сообщения Gemini.
- `lib/services/` — хранение сада и отдельные интеграции: Gemini HTTP-клиент, prompts, разбор ответа/исключения, уведомления, Secure Storage.
- `lib/models/` — данные растения и предпочтения сада.
- `test/` — unit/widget-тесты бизнес-логики и основных пользовательских действий.

Состояние сада обновляется через `PlantStore extends ChangeNotifier`; экраны подписываются через `ListenableBuilder`. Сейчас этого достаточно, поэтому дополнительный пакет state management специально не добавлен.

## CI

`.github/workflows/flutter.yml` запускает на GitHub Actions под Windows `flutter analyze`, `flutter test` и Release-сборку приложения при push/pull request, а также позволяет запустить проверку вручную.

## Как устроен уход

Сад можно показывать сеткой компактных карточек или списком широких горизонтальных карточек; переключатель находится у поиска и выбор сохраняется на устройстве. Кнопка **Подробнее** открывает полную страницу растения с фото, уходом, условиями, личными заметками и историей поливов. Сезонная частота рассчитывается как ориентир для Северного полушария; фактическую влажность грунта всё равно нужно проверять перед поливом.

## Время напоминаний

Общий час и минуты настраиваются в **Настройки → Время напоминания о поливе** (24-часовой формат). Значение по умолчанию — 09:00. Выбранное время сохраняется локально в защищённом хранилище приложения, применяется ко всем растениям и перепланирует ближайшие уведомления. Экспорт `.ics` тоже создаёт события на выбранное время; при дальнейшем изменении сада экспорт следует обновить вручную.

## Внешний вид и первый запуск

При первом запуске новый пользователь видит короткий onboarding, а затем вводит свой Gemini API-ключ. Можно выбрать светлую, тёмную или системную тему в настройках. На главном экране есть сводка состояния сада, пустое состояние с быстрым добавлением растения и компактные карточки с сеточным или списочным отображением. Брендированная иконка установлена для Android, iOS, Windows и Web; её исходник находится в `assets/brand/floraqua_icon.png`.

## Gemini API-ключ и ошибки

На первом запуске приложение запрашивает персональный ключ пользователя. Ключ хранится в Secure Storage этого устройства и используется напрямую только для запросов этого пользователя. Приложение не содержит общего ключа разработчика. Сетевые сбои и таймауты показываются отдельно от ошибок, пришедших от Gemini API; 429 остаётся отдельной ошибкой квоты. Если в будущем планируется единый ключ сервиса, его нельзя вшивать в приложение — для этого нужен серверный прокси.
